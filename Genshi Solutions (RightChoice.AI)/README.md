# 🧑‍💻 Fetch Users from Public API using Python

## 📖 Project Description
This project demonstrates how to fetch and display data from a public API using Python.  
It uses the `requests` library to call the API and display user details in a readable format.

**API Used:**  
🔗 https://jsonplaceholder.typicode.com/users

The script displays:
- Name  
- Username  
- Email  
- City (from address.city)

It also includes:
- ✅ Error handling for failed API calls  
- ✅ (Bonus) Filtering users whose city name starts with the letter 'S'
